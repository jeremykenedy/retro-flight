# Retro Flight 1.0.0

First stable release of the animated Retro Flight screensaver.

## Changes

- Added continuous animated starfield flight, moving ringed planet, horizon glow, and optional perspective grid.
- Added randomizable star density, speed, palette, field, and glow settings.
- Added remote settings, in-app preview, validated settings provider, and standalone installer.
- Added signed APK release and SHA-256 verification.

## Compatibility and verification

The app targets Android 6.0 (API 23) and later. Android TV emulator behavior was verified at 1920x1080. Physical Fire TV, Android TV, and Google TV devices remain untested. See the [device matrix](../VERIFICATION.md).

## Installation and upgrade

Install with `python3 install.py --serial TV_IP:5555`, or use the manual steps in [installation](../INSTALLATION.md). Future in-place updates require the same package ID and release signing certificate. The installer does not change device screensaver selection or system settings.

This first release has no prior version to upgrade from and introduces no breaking changes.
